# Changelog

## 1.0.0

- Mac and Windows packages with guided Setup and Start files.
- User-local `yt` / `dd` launch commands, dependency checks and separate per-user settings.
- Same format/quality/optional-menu flow, original selected video codec, FPS/HDR and size colours.
- Interactive trim keys on both desktop systems; process-tree pause/resume on Windows.
- Green progress and downloaded/total size; validated output and saved-folder display.
- English/Hindi setup guides, troubleshooting, bug-report form and desktop CI checks.

No hosted service or mobile app is included. Website availability and login requirements depend on yt-dlp and the website.
